# Portfolio

A portfolio website built with Next.js, featuring live project previews in iframes, GitHub integration, and dark/light mode toggle.

## Features

- Display projects from GitHub
- Live demo previews in iframes
- GitHub repository links
- Dark and light mode toggle

## Getting Started

First, install dependencies:

```bash
npm install
```

Then, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Customization

- Update the GitHub username in `app/components/Projects.tsx` to fetch your repositories.
- Modify the about section in `app/page.tsx`.

## Deploy

Deploy on Vercel or any platform supporting Next.js.
