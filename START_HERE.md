## 🚀 Quick Start (3 Steps)

### Step 1: Customize Your Data (5 min)
```bash
# Edit your personal information
nano app/data/resume.ts

# Update:
# - Your name, title, description
# - Work experience (3 entries included)
# - Skills & proficiency levels
# - Featured projects
# - Certifications & education
# - Testimonials
# - Social media links
```

### Step 2: Add Your Images (2 min)
```bash
# Add your profile photo (required)
cp ~/profile.jpg public/image/profile.jpg

# Add your resume PDF (required)
cp ~/my-resume.pdf public/resume.pdf

# Add project screenshots (optional)
cp ~/project*.jpg public/projects/
```

### Step 3: View & Deploy (2 min)
```bash
# Run locally
npm run dev
# Visit: http://localhost:3000/resume

# Deploy (Vercel recommended)
vercel deploy
```
