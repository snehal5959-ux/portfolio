## 🎨 Color & Component Details

### **Card Styles**

**Default State:**
```
Border: rgba(128,128,128,0.4) 1px
Background: gradient from rgba(255,255,255,0.05) to rgba(255,255,255,0.02)
Shadow: none
```

**Hover State (Neon Glow):**
```
Border: rgba(0,255,255,0.5) → rgba(0,255,255,1)
Background: color-specific glow (10-30% opacity)
Box-shadow: 0 0 20px rgba(0,255,255,0.6), 0 0 40px rgba(0,255,255,0.3)
Transition: 300ms ease-out
```

### **Button Styles**

**Primary (CTA):**
```
Background: gradient from cyan-500 to cyan-400
Padding: px-8 py-4
Font-weight: bold
Border-radius: rounded-lg
Box-shadow on hover: shadow-lg shadow-cyan-500/50
Scale on hover: 105% with smooth transition
```

**Secondary (Links):**
```
Border: neon color at 50% opacity
Color: neon color text
Background: transparent or white/5 on hover
Padding: px-4 py-2 (smaller)
Border-radius: rounded-lg
```

## ✨ Animation Timings

**Section Load:**
- Initial: offset 20px down, opacity 0
- Final: 0px, opacity 1
- Duration: 0.5-0.6s
- Easing: ease-out

**Stagger Children:**
- Delay between items: 0.1-0.2s
- First item: 0s
- Each subsequent: +0.1s

**Progress Bars:**
- Trigger: whileInView
- Duration: 0.8s
- Width: 0% → target%
- Easing: easeOut

**Hover Effects:**
- All transitions: 0.3s duration
- Scale: 1.02-1.05
- Smooth cubic-bezier easing
